# English Steps

تطبيق أندرويد لتعلّم الإنجليزية يعمل دون إنترنت (الإنترنت فقط لتسجيل الدخول والتفعيل).

## ما يحتويه الآن
- واجهة بثلاث لغات: العربية، الفرنسية، الإنجليزية.
- امتحان تحديد المستوى (A1 → C1) ثم مسار دروس على مقاس المستوى.
- 5 مستويات × 6 وحدات: كلمات مرسومة مع النطق، قواعد مشروحة بأمثلة، محادثات مسموعة، وتحدي لكل وحدة.
- اختبار تجاوز المستوى (20 سؤالًا، النجاح بـ 80%).
- 6 ألعاب: طابق الكلمات، اسمع واختر، بطاقات الذاكرة، سباق الدقيقة، صانع الكلمات، بنّاء الجمل.
- مراجعة ذكية للكلمات (خوارزمية لايتنر)، نقاط، سلسلة أيام، هدف يومي، صندوق مكافأة، أوسمة.
- الجانب المجاني: أول وحدتين من كل مستوى + 3 ألعاب + المراجعة + تحدي اليوم.
- الجانب المدفوع (300 أوقية / 45 يومًا): كل الوحدات، اختبار تجاوز المستوى، كل الألعاب. عند التجديد يواصل المستخدم من حيث توقف.

## المحتوى
المحتوى مكتوب في `tools/content/*.py`، ويُبنى منه `app/src/main/assets/content.json` بالأمر:

```
python3 tools/build_content.py
```

يدوي فقط: تبويب Actions ← Build APK ← Run workflow.
